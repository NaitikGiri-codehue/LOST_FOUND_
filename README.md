# 🔗 PROJECT STATEMENT

## 🔗 PROJECT TITLE

**Lost and Found College Management System**

## 🔗 INTRODUCTION

The Lost and Found College Management System is a simple Python project made to manage lost and found items in a college.

In college, students may lose things like ID cards, wallets, books, bags, keys, water bottles, earphones, and other personal items. Sometimes another student may find the item but may not know who it belongs to.

This project provides a simple way to report lost and found items. Students can also view the items, search for them, and claim an item if it belongs to them.

## 🔗 PROBLEM STATEMENT

In a college, there may not be a proper system to manage lost and found items.

When students lose something, they usually ask their friends, search different places, or send messages to other students. If someone finds an item, it can also be difficult to find its owner.

Because of this, many lost items may remain unclaimed.

This project is made to provide a simple and organized way to record, search, display, and claim lost and found items.

## 🔗 AIM OF THE PROJECT

The main aim of this project is to create a simple Python program that can help students manage lost and found items in a college.

The system keeps the item information in one place so students can easily check the available records.

## 🔗 OBJECTIVES

The main objectives of this project are:

* To report lost items.
* To report found items.
* To store information about the items.
* To display lost and found items.
* To make searching for items easier.
* To provide a simple way to claim an item.
* To divide the program into different Python files.
* To use basic Python concepts in a real-life project.

## 🔗 SCOPE OF THE PROJECT

This project is mainly made for use in a college.

Students can report the items they have lost and can also check the items that have been found by others. A student who finds an item can report it so that the owner can find and claim it.

The current project is a basic version of a Lost and Found system. In the future, more features can be added to make it more useful.

## 🔗 MAIN FUNCTIONS

The system has the following main functions:

1. Student Login
2. Report Lost Item
3. Report Found Item
4. Display Lost and Found Items
5. Search Items
6. Claim an Item
7. Generate Reports

## 🔗 PROJECT MODULES

The project is divided into six main Python files:

```text
main.py
login.py
student.py
report.py
display.py
claim.py
```

Each file has a different purpose.

`main.py` is used to run and control the main program.

`login.py` is used for student login.

`student.py` is used to manage student information.

`report.py` is used to report lost and found items.

`display.py` is used to display the available item records.

`claim.py` is used to handle the item claiming process.
