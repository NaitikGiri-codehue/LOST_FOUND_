# 🔗 Lost and Found College Management System

## 🔗 Project Overview

The **Lost and Found College Management System** is a simple Python-based project designed to help students manage lost and found items inside a college campus.

Students can report items they have lost, add details about items they have found, search for items, and manage the claiming process. The project provides a simple way to organize lost and found information instead of depending only on verbal communication.

## 🔗 Objectives

The main objectives of this project are:

* To record lost items in the college.
* To record items found by students.
* To display lost and found item details.
* To help students search for their belongings.
* To provide a simple claiming system.
* To make the process of managing lost and found items easier.

## 🔗 Description of Files

### main.py

This is the main file of the project. It controls the overall flow of the program and provides the main menu to the user.

### login.py

This file handles the basic login part of the system.

### student.py

This file is used to store and manage student details related to lost and found items.

### report.py

This file is used to report lost or found items and collect their required information.

### display.py

This file displays the available lost and found items to the user.

### claim.py

This file handles the claiming process when a student finds their lost item.

## 🔗 Main Features

### 1. Student Login

Students can enter their basic login details to access the system.

### 2. Report Lost Item

A student can enter information about an item they have lost, such as:

* Item name
* Category
* Location
* Date
* Description
* Student name
* Contact details
* Status

### 3. Report Found Item

Students can also enter details about items they have found on the college campus.

### 4. Display Items

The system can display the recorded lost and found items so that students can check the available information.

### 5. Search Items

Students can search for items using details such as:

* Item name
* Category
* Location

### 6. Claim Item

If a student finds their lost item in the system, they can use the claim section to start the claiming process.
