# LOST_FOUND_
Lost and Found Management System
➜ About the Project

The Lost and Found Management System is a beginner-level Python project developed to manage lost and found items within a college campus. The main purpose of the project is to provide students with a simple and organized way to report items they have lost or found and to check the records available in the system.

Losing personal belongings is a common problem for students. Items such as ID cards, wallets, books, bottles, headphones, keys, and other belongings can easily be misplaced around the campus. At the same time, students who find these items may not know how to return them to their owners.

This project provides a basic solution by bringing the reporting, displaying, and claiming processes together in one system. It also demonstrates how basic Python concepts can be used to create a practical real-world application.

➜ Problem Statement

Students may lose their personal belongings at different places around the campus, while other students may find these belongings without knowing who they belong to. In many cases, information about these items is shared informally, making it difficult to keep track of multiple lost and found items.

The Lost and Found Management System provides a structured way to record and manage this information. It allows students to report lost or found items, view available records, and use the claiming section when a found item belongs to them.

➜ Main Features
➜ Student Login

The login module provides a basic login facility for students using the system. It forms the initial part of the user interaction and helps organize access to the different features.

➜ Student Information

The student module manages information related to students using the system. Keeping this functionality separate makes the overall program easier to understand and maintain.

➜ Reporting Items

The report module is used to record information about lost and found items. Students can provide the necessary details about an item so that the information can be viewed by other users.

➜ Displaying Items

The display module is responsible for showing the available lost and found records. Students can use this section to check whether an item they are looking for has already been reported.

➜ Claiming Items

The claim module manages the process of claiming a found item. It provides a separate part of the system where students can proceed with the claiming process.

➜ Main Program

The main.py file acts as the central part of the project. It connects the different modules and provides the main menu through which the user can access the available features.

➜ Project Structure

The project contains six main Python modules:

➜ main.py – Controls the overall program and connects all the modules.

➜ login.py – Handles the student login functionality.

➜ student.py – Manages student-related information.

➜ report.py – Handles reporting of lost and found items.

➜ display.py – Displays the reported lost and found items.

➜ claim.py – Handles the claiming process.

The project also contains documentation files such as README.md and statement.md.

Using separate modules helps keep the program organized instead of placing all the functionality in a single Python file.
