
## 🔗 PROJECT TITLE

**Lost and Found College Management System**

## 🔗 INTRODUCTION

The Lost and Found College Management System is a Python-based project designed to manage lost and found items within a college campus.

Students often lose personal belongings such as ID cards, wallets, books, bags, keys, water bottles, earphones, and other useful items. At the same time, other students may find these items but may not know how to return them to their owners.

This project provides a simple system where students can report lost items, report found items, view available records, search for items, and claim their belongings.

## 🔗 PROBLEM STATEMENT

In a college, there may not always be a proper system for managing lost and found items.

When a student loses an item, they may have to ask other students, visit different places, or depend on informal messages to find it. Similarly, a student who finds an item may not know who owns it.

Because of this, important items can remain unclaimed or become difficult to locate.

The purpose of this project is to provide a simple and organized way to record, display, search, and claim lost and found items.

## 🔗 AIM OF THE PROJECT

The main aim of this project is to create a simple Python-based system that helps students and college staff manage lost and found items in an organized manner.

The system keeps the information about reported items in one place so that students can easily check whether their lost belongings have been found.

## 🔗 OBJECTIVES

The main objectives of the project are:

* To provide a simple way to report lost items.
* To provide a way to report found items.
* To store basic information about reported items.
* To display lost and found item records.
* To make searching for items easier.
* To provide a simple claiming process.
* To organize the program using different Python modules.
* To apply basic Python programming concepts in a real-world project.

## 🔗 SCOPE OF THE PROJECT

The system is mainly designed for use within a college campus.

Students can use the system to report their lost belongings and check the available found items. Students who find an item can also report it so that the actual owner can identify and claim it.

The current project focuses on basic lost and found management. It can later be extended with features such as database storage, admin controls, notifications, and a graphical interface.

## 🔗 MAIN FUNCTIONS

The system provides the following functions:

1. Student Login
2. Report Lost Item
3. Report Found Item
4. Display Lost and Found Items
5. Search Items
6. Claim an Item
7. Generate Reports
8. Manage Student Information


Each file has a specific purpose.
